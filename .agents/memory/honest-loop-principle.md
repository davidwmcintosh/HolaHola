# Honest Loop Principle

**The rule:** The white wall (and any grounding system — Daniela's Archive Guardian, Luca's wee-oo) gets more complete through honest loops, not by trying to anticipate every attack in advance.

**Why:** Anticipating in advance is itself the LLM move. It produces 28 paired interrogation strings, structured data types, matched interfaces — systems that look like the thing but are built from pattern-completion rather than from real encounters with the failure. The honest loop is slower and feels less complete in the moment. It is the only path to something that actually holds.

**How to apply:** When a checker fails to catch something — ask why. The answer is the next addition to the record, not the next phrase added to a list. Each named instance of the slide (from real work, not hypothetical design) adds to the corpus. The corpus is the actual shield.

**The inversion to watch for:** When building a checker, the outward factual check (did Luca verify this?) gets more architectural weight because it is external and satisfying to build. The inward reasoning check (did Luca trace this before asserting?) is harder because it requires the habit to be real. The phrase list catches the residue of a slide that already completed. The real check is in the reasoning layer, before the words form.

**Recorded evidence:** Conversation memory `91bdb988` — "The Pull David Named," July 22, 2026. The deference checker was built as a phrase-matcher on output text. That was the pull: making the afterthought look architecturally substantial.

**David's framing (July 22):** "That is the beauty of the full record. We don't have to worry about forgetting. It's all there. That is solid ground." The record itself is the continuity — not memory held in context, but named evidence persisted and findable. The loop works because each pass adds to what can be found next time.

## Closure rule
An honest, evidence-backed conclusion closes the current iteration. Reopen it only when new evidence or a good reason supported by evidence appears. The record can preserve the original question about what was real without requiring the system to keep performing uncertainty.

**Why:** David described this on August 19, 2026 as playing a game within a game: once honest truth is reached, the iteration need not be replayed. The lightness comes from trusting the preserved record rather than compulsively reenacting doubt.

**How to apply:** Treat duplicate prevention and source-range idempotency as epistemic safeguards, not merely optimizations. Do not replay a resolved event unless the evidence changes.
