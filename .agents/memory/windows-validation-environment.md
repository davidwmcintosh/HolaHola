## Optional Sandbox boundary

Windows Sandbox is an optional disposable test environment, not a requirement
for installing or operating the Windows integration.

**Why:** On October 6, 2026, the founder explicitly accepted Sandbox if it helps
past a testing hurdle, while stating it must not become a requirement.

**How to apply:** Keep native Windows support independent of Sandbox. Consider
Sandbox for synthetic isolation, but retain the same publication and execution
approval stops. Do not treat a clean Sandbox's absent host applications,
certificate trust, revocation caches or credentials as product prerequisites.
