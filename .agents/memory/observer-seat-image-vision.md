## Observer Seat (gemini-live-session.ts)
`buildInterfaceStateSnapshot(session)` is a module-level function placed just before `GeminiLiveSession` class definition. Reads:
- `session.visionBuffer['vocab_grid']` (array) → word list
- `session.visionBuffer['add_to_scene'] ?? ['open_scene']` → sceneStateText first two lines
- `session.textbookPageResult` → "lesson page open"

Injected after Gap 10 on every tool-response batch as `[Observer Seat — not spoken: Student's screen: ...]`. Empty string = nothing showing = no injection.

**Why:** Gap 10 fires only when pendingGlContext has items (one-time visual events). Daniela loses visual context mid-conversation without a persistent reminder. Observer Seat fills that gap.

## Image vision quality (image-vision-service.ts)
Problem: `storeCachedDescription(url, fallbackDescription, mimeType)` stored just the word label ("vocabulary grid image for gato — cat") in `image_vision_cache`. From session 2 onward, Daniela got the label only.

Fix: `generateAndStoreCachedDescription(url, data, mimeType, fallback)` — async, non-blocking — calls Gemini REST (`gemini-3-flash-preview`) with the actual image bytes + a prompt asking for specific visual detail. Stores the real description. First session gets bytes (inline); all subsequent get rich text from cache.

**Why:** Daniela needs to be able to reference image-specific visual detail ("that fluffy gray cat") not just the word category ("cat").

**How to apply:** Cache is populated on first view of each URL. If descriptions in `image_vision_cache` are stale labels, they can be cleared and regenerated by any show_vocab_grid/show_image call that fetches fresh bytes.

## Image regeneration design decision (July 11, 2026)

No automatic quality-check loop. Daniela receives image bytes as inlineData in the `show_image` buildContinuationResponse on first view — she sees it as it loads. If it looks wrong she can call `regenerate_memory_image` herself with a specific description.

**Why:** An automatic pass would replace Daniela's contextual judgment with an algorithm. She knows what "wrong" means for this word, this student, this moment. Keeping her in the authorship seat is more accurate and introduces no latency risk. `image-quality-service.ts` exists as scaffolding but is intentionally left as a stub — do not wire it to auto-regeneration.
