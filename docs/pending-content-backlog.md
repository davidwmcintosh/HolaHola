### Page 60 — Querer / Lo quiero / La quiero
**Overlap:** Ch. 32 (I Want: Quiero) covers querer + infinitive, but NOT direct object pronouns lo/la.  
**Note:** Lo quiero / La quiero introduces direct object pronouns (lo = him/it masc.; la = her/it fem.) — a new grammar concept. This is the first appearance of lo/la as pronouns in Madrigal's sequence.  
**Spanish 1 or 2?** The expressions themselves are very natural Spanish 1 content, but the grammar concept (direct object pronouns) usually sits at Spanish 2. Keep the phrases as vocabulary; defer the formal grammar treatment.  
**Verdict:** Can fold the expressions into Ch. 32 as a "saying it about people" cluster — teach the phrases without formally naming the pronoun rule.

### Page 198 — Commands (Formal Imperative) → **Spanish 2**

This is the formal command (usted) form — solidly Spanish 2 / Intermediate Low grammar. Document here for completeness but do not build into Spanish 1.

**Rule:** AR verbs → drop -ar, add -e. ER/IR verbs → drop -er/-ir, add -a.

| Infinitive | Command | Example |
|---|---|---|
| hablar | hable | Hable despacio (Speak slowly) |
| mirar | mire | Mire (Look) |
| contestar | conteste | Conteste el teléfono (Answer the phone) |
| tomar | tome | Tome esto (Take this) |
| vender | venda | Venda la casa (Sell the house) |
| aprender | aprenda | Aprenda la lección (Learn the lesson) |
| escribir | escriba | Escriba (Write) |

**Irregular GA commands:**

| Infinitive | Command | Example |
|---|---|---|
| oír | oiga | Oiga (Hear / Listen) |
| traer | traiga | Tráigamelo (Bring it to me) |
| venir | venga | Venga acá (Come here) |
| hacer | haga | Hágalo (Do it) |
| decir | diga | Dígame (Tell me) |

**Note:** Pronoun attachment to command (escríbame, tráigamelo) also appears here — pronoun attachment is part of the same Spanish 2 command unit.
