# Spanish 1 Curriculum Restructuring Plan
**Status:** Design Phase — April 5, 2026  
**Scope:** Spanish 1 - High School  
**Current:** 9 units (chapters) → **Proposed:** 27 chapters  
**Method:** Simultaneous reorganization + content gap fill (no re-audit needed)

---

## Content Standards (agreed targets)

| Standard | Target | Notes |
|---|---|---|
| Vocab per chapter | 10–14 items | Numbers/colors may go to 15; not a hard ceiling |
| Phrases per chapter | 4–6 | Fixed expressions, question patterns, social formulas |
| Grammar per chapter | 1–3 concepts | Must be intellectually related; no duplicate counting |
| Total cognitive load | ≤ 20 distinct items | The "one sitting" rule |

**Grammar counting rules:**  
- Count structural grammar only: conjugation paradigms, pronoun systems, agreement rules, negation, interrogative formation  
- Do NOT count: fixed expressions, vocabulary patterns, courtesy phrases, question words used as vocabulary  
- Do NOT count duplicates across lessons within the same chapter  

---

## The Lesson-to-Chapter Mapping Rule

The natural split line is the existing lesson title. Each lesson either:
- **Stands alone** as its own chapter (when it has 12–14 vocab and a clear theme)
- **Merges with one sibling lesson** (when two lessons are thematically inseparable and combined stay within 20 items)
- **Gets new content added** (when it's thin: <10 vocab, <3 grammar concepts)

Culture Corner lessons become **Cultural Spotlight sections within their nearest thematic chapter**, not standalone chapters.

## Migration Script Plan

**Script:** `server/scripts/restructure-spanish1.ts`  
**Safe to run repeatedly:** Yes — checks for existing units before creating  
**Rollback:** Keep original unit IDs as `deprecated: true` flag (or rename to `[ARCHIVED]`)  

**Operations:**
1. For each new chapter: `INSERT INTO curriculum_units` with new name, new order_index  
2. For each lesson → new chapter mapping: `UPDATE curriculum_lessons SET curriculum_unit_id = new_unit_id`  
3. Mark old mega-units as archived (rename + set active=false if column exists, or delete after validation)  
4. Update `chapter_intro_content.ts` with new chapter type keys  

**Sequencing:** Chapters 1–27 in order; lessons that move retain their content exactly; chapters with "EXPAND" flag get a new skeleton lesson added with a TODO marker for content fill
